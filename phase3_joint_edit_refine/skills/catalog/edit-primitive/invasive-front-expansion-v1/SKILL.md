# Invasive-front expansion

Use this primitive for a true displacement of an invasive tumor front into a
mechanism-authorized adjacent structural compartment. It always changes tissue
and regenerates a coupled neoplastic population. It is not a synonym for
tumor budding, STAS, single-file cells without tissue displacement, or Gleason
pattern conversion.

Read `references/primitive_contract.json`; the selected domain mechanism owns
the legal source/target labels, front geometry and nuclei layout.
