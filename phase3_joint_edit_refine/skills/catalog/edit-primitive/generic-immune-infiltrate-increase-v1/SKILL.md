# Generic immune-infiltrate increase

Read `references/primitive_contract.json`. This primitive changes an existing
Stroma-to-Immune-infiltrate interface and regenerates an inflammatory
population. It does not identify lymphocyte subsets, plasma cells,
macrophages, treatment response, prognosis or clinical benefit.
