# Neoplastic microinfiltration increase

Use this primitive only when the tissue label must remain unchanged and a
domain mechanism permits neoplastic cells in a verified non-tumor host zone.
The mechanism—not this primitive—defines whether the executable layout is a
single cell, pair, one-to-four-cell bud, short chain or other small template.

Read `references/primitive_contract.json` before compilation. Do not use this
primitive for bulk front displacement, STAS/airspace spread, or a change in a
fine architectural identity.
