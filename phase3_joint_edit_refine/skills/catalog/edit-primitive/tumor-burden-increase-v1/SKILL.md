# Tumor burden increase

1. Require a real source-to-tumor tissue interface and a nonzero tissue edit.
2. Preserve every unrequested tissue label and protected structure.
3. Regenerate the changed region with the target-tumor population contract before applying a mechanism modifier.
4. Allocate structured cells inside the fixed total population quota unless an independently budgeted cell-only primitive is present.
5. Read [primitive_contract.json](references/primitive_contract.json) for the executable scope, budget, and checker contract.
