# Tumor burden decrease

1. Require a broad tumor-to-target interface and a nonzero tissue retreat.
2. Reject deep notches, partial structural cuts, and undeclared target tissue.
3. Remove intersected source nuclei only as complete instances.
4. Regenerate the exposed target tissue with its own population contract.
5. Read [primitive_contract.json](references/primitive_contract.json) for executable requirements.
