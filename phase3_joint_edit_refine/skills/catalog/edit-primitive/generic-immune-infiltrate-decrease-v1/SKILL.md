# Generic immune-infiltrate decrease

Read `references/primitive_contract.json`. This primitive changes an existing
Immune-infiltrate-to-Stroma interface and removes complete inflammatory
instances from the converted region. It does not claim immune suppression,
treatment response, prognosis or a specific immune-cell subtype.
