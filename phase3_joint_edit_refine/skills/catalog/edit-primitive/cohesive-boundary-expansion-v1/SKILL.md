# Cohesive Boundary Expansion

Use this primitive only for a tissue-and-cell increase from a certified external Tumor--host interface. Read the selected domain mechanism and annotation profile before planning.

- Select only deterministic interface and anchor IDs.
- Prefer broad, shallow, connected change over a deep local notch.
- Preserve every unrequested fine label and protected structure.
- Require complete-instance source turnover and target-population regeneration.
- Do not infer an invasive front, histologic subtype, or host identity from H&E.
