# Peritumoral Tumor Nest Formation

Use for an explicitly requested tumor nest or island near an invasive front.

- Execute `irregular Tumor island -> tumor cells`; this is tissue-first and intentionally differs from cord formation.
- Place one compact island in the certified host-side peritumoral band with a measurable gap from the parent Tumor.
- Give the island a compact but mildly irregular boundary; reject a perfect disk, long cord, broad sheet, bridge, or remote focus.
- Authorize exactly one new Tumor component and no new holes or merges.
- Fill the island with six to twelve complete source-scaled neoplastic nuclei using the existing nuclei channel; reject one-to-five-cell bud-like results as too small for this primitive.
- Report a synthetic Tumor nest/island, not a diagnostic budding score or metastatic deposit.

Read `references/primitive_contract.json` and `references/evidence.json` before execution.
