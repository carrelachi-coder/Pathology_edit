# R2：最新版 mask edit 的结果叙事与 Figure 2 方案

更新日期：2026-09-22。代码基线：final-mask-edit，f1780ee；本次新增多步程序生成交接接口，未改动原语、采样器、验收阈值或模型权重。

## 推荐定位

英文标题：**Language-guided editing constructs annotation-aware tissue and cellular counterfactual states**

中文中心结论：**自然语言指定的形态学干预，可以在病理知识、标注语义和当前组织状态的约束下，转化为可检查的组织与细胞反事实状态。**

R1 介绍整体系统和代表性 H&E 示例，R2 证明“目标状态如何被正确构建”。R2 的主要对象是 tissue/nuclei mask 及其编辑记录。生成 H&E 是否真正表现出这些改变属于 R3；跨样本连续强度与剂量单调性属于 R4；诊断变化与盲评属于后续 Results。不要在 R2 把 mask gates 通过等同于医生认可或图像达到目标。

建议五段。以下“结论”是各段需要回答的命题，尚无相应统计时不能写成已完成的定量结果。

## 第一段：语言表达可以变化，但生物学操作必须明确

**中心结论：语言接口应保持用户的生物学意图，而不是根据措辞或治疗背景擅自更换操作。**

主要内容：

- Parser 接收文本，解析 target、operation、polarity、clinical context、spatial scope、morphology、cell class、strength 及顺序，不输出 primitive、坐标或细胞数量。
- 区分直接指令（扩大肿瘤范围）与临床语境指令（模拟治疗后残余肿瘤减少）；仅有“治疗后”而没有方向时，不自动推断改善。
- 否定、顺序、歧义和冲突保留到后续规划；存在不同可行含义时进入澄清状态。
- 可以引用现有的冻结合成语言测试：87 条 held-out 指令（冻结的 gpt-4.1-mini API 配置），中文 43、英文 44，闭集语义与后续目录级 Planner exact 均为 87/87。准确称为“catalog-derived bilingual interface audit”，不是临床自由语言泛化或端到端 mask 成功率。
- 上述 87/87 不自动转移到换用的新 Parser 模型或新提示词。当前 strength 的文字标签不等于自动校准的面积/数量。Panel C 使用显式数字预算，正文和图注要说清。

实现口径：仓库仍有可选的多模态 LLM 候选选择器，CLI 的 API 模式会启用它们。Panel C 使用 prebound semantic request + offline deterministic execution。因此不能笼统宣称“仓库所有路径都只有 Parser 使用 LLM”，也不能把 Panel C 当作一次实际在线 Parser 调用。主实验应先冻结配置；若采用纯确定性 mask planning，可先冻结 API Parser 输出，再以 prebound/offline 路径执行，并记录两阶段绑定。

**现有证据**：自然语言 holdout report、schema 与 program tests。

**需要补什么**：若只保留受限接口结论，不需要重做大规模语言测试。若要加强自然表达证据，补 36 条未参与模板构建的独立改写，包含直接编辑、明确治疗反应、否定、顺序、歧义及矛盾各 6 条。先由研究者独立标答案，再冻结后调用 Parser，不根据结果改 GT。临床表述请医生核对一个小子集即可。

**对应 Figure 2a**：3 组不同措辞，进入结构化意图，再到允许的操作；旁边放 87 条接口测试的小表。歧义句用分叉到“clarification”，不要画成系统自动猜出确定诊断。

## 第二段：组织范围、浸润结构和细胞群体是不同的干预对象

**中心结论：系统构建可区分的多尺度形态学状态，而不是用同一种扩大/缩小去替代所有生物学操作。**

主要内容：

- 三类操作层级：组织/病灶范围，局部浸润结构，细胞组成。
- 重点解释容易混淆的两组：肿瘤组织范围缩小与组织范围内肿瘤细胞减少；免疫富集组织区室扩大与炎症细胞数量增加。
- 使用实际 source→target tissue/nuclei mask 展示所改对象，以及必须保留的对象。
- 细胞编辑由源图的数量/类别证据、完整参考核形状、合法放置范围和 ProbNet 空间概率共同实现。不要称 ProbNet 自己生成核轮廓或决定用户要求的数量。
- 20 种开放 semantic primitive、74 个 organ–annotation-profile bindings 是冻结目录的范围描述，不能写成 74 个绑定都已有同等成功率或全部经过医生验证。

**现有证据**：最新 catalog、已有 primitive panels，以及本次 Panel C 的三种实际编辑。Panel C 只覆盖其中少数操作，不代表整个目录。

**需要补什么**：冻结最新版执行配置和 manifest，至少报告每个绑定的可用样本数、尝试数、通过数、拒绝/需澄清数、异常数。对 tissue 记录类别面积变化；对 cell-only 记录实例事件和组织 mask 保持情况；对 architecture 记录原语特异几何，不用同一面积指标衡量一切。

**对应 Figure 2b**：3 行真正不同的操作，不重复 R1 的 3×2 H&E 拼图。推荐“连续边界扩张”“离散小簇/条索中的一种”“指定细胞群体增加”。列为原始联合 mask、目标联合 mask、变化叠加与一个真实测量值。H&E 只放一个小参考缩略图，不把生成真实感变成这一 panel 的主旨。

## 第三段：同一生物学请求必须按标注体系解释

**中心结论：标注语义约束哪些改变可以表达，以及哪些空间规则可以合法执行。**

主要内容：

- 先说明同一标签名称、同一解剖结构在不同数据集并非相同的像素对象。
- 用 GLaS 完整腺体单位与 PANDA pattern 上皮作对照，解释为什么腔隙/腺体边界不能套同一条规则。具体图按实际 annotation profile 和可用辅助 mask 画，不凭 H&E 虚构不存在的 lumen 标注。
- 病理机制目录给出生物学允许的操作，annotation profile 决定可观测的表示，当前 mask 的边界/连通域/完整核决定该例是否可执行。
- “目录支持”“当前病例可执行”“执行后通过检查”是三个不同状态。缺标签或缺结构证据不是执行成功，也不是随机失败。

**现有证据**：profile catalog、当前层级 scene、辅助结构 digest 规则。

**需要补什么**：优先复用最新 GLaS/PANDA 已核查样本，各选 3–4 个适合展示的病例。若宣称“显著减少结构破坏”，才需要 frozen ablation：同一输入/预算/种子，比较 annotation-aware 与预先定义的统一规则，列出结构违规和拒绝情况；不能把本来不兼容的操作强行执行，再算一个有利胜率。精简方案可以只作机制说明，删除改善幅度的主张。

**对应 Figure 2c**：左右 GLaS/PANDA 两列，上方实际标注对象，中间同一抽象请求如何映射，下方合法编辑/受保护结构。完整 20×6 coverage 矩阵放补充图，主图只保留信息密度较高的几个 profile 差异。

## 第四段：可执行性和效果量由约束检查，而不是选择漂亮图片

**中心结论：系统只提交满足当前状态约束的候选，不能兑现的请求会被记录为失败、拒绝、超时或澄清。**

主要内容：

- mask gates 检查方向与数值预算、合法标签转换、完整核、放置范围、保留对象和可用结构约束。
- J 是组织/细胞改变的联合范围；G 是生成器需要重绘的支持区域。两者不同，G 不可当作肿瘤增幅或用户 strength。
- 当前 case 单次高预算遇到采样配额/面积收敛问题，说明成功有状态依赖。超时只表示给定计算预算内未完成，不能直接解释为生物学不可行。
- 保留所有预定尝试的分母。若报告自动修复，只计算同一冻结策略内的重试，不能把人工改预算、换种子或改成多步程序计为原请求自动恢复。
- 将 accepted-mask constraint validity 与 attempted-request execution yield 分开。前者可能接近 100% 因为有筛选，不能据此称所有请求都可靠。

**现有证据**：确定性 checker、逐例 gate reports 和 Panel C 失败记录。旧 14,288 条/99.92%/369 of 380、旧细胞采样 1,457 或 63,304 等不属于这版联合 mask editor 的新主结果。

**需要补什么**：新版冻结执行队列。至少给 attempted、validated、clarification/review、abstained/failed、timeout/runtime error 的明确定义与互斥计数。面积/数量误差只在适用原语内统计，同时报告未成功请求。样本是同一 WSI 时按 WSI 聚类，不能把同图多强度当独立病例。

**对应 Figure 2d–e**：d 是按 profile 或操作层级分组的执行状态堆叠条，标清 n；e 是实际目标偏差和保留约束的散点/分布，旁边一个代表性失败例。没有新数据前只做设计占位，不画虚构柱高和误差棒。

## 第五段：多步干预在更新后的状态上继续执行

**中心结论：反事实状态可以逐步构建，但每一步都要重新检查，累计输出必须相对原始状态计算。**

主要内容：

- 当前程序支持显式有序意图；每步通过→提交 mask→更新 scene→下一步，任一步失败就停止。
- 本次已验证的具体例子：同一原图 49.3% tumour，低档 54.7%，两步累计高档 60.2%；高档相对原图 +10.9 个百分点，G 为 23.7%。第一步 tissue/nuclei mask 与低档完全相同。
- 两次 6% 是两步 joint edit budgets，不是一次 12% 肿瘤增幅；此例是“有序重复同类干预”，不能凭它证明所有异类操作任意可组合。
- 正式程序交接保留原始参考图、最终 mask 和各步 G 的并集；global 是显式选择，不能写成达到 50% 阈值后自动触发。
- 这属于状态操作序列，不代表随访时间、真实治疗预测或 Grade 1→2→3 的连续临床轨迹。

**现有证据**：本次两步 mask 程序、逐步检查及最终模型推理。新增接口完成的是可复用交接，不是新增训练出来的生物学能力。

**需要补什么**：要在本段写一般性 compositional editing，补 12 个冻结有序程序：4 个重复干预、4 个不同对象的有序干预、4 个预设的冲突/后续不可执行程序。失败在预期条件下正确停止也是一个独立的正确行为，但不计入“完成了有效最终状态”。如要判断顺序效应，需要另做 A→B/B→A 配对并预先定义评价。

**对应 Figure 2f**：用当前 case 的完整 mask，画 S0→S1→S2，显示 T/N 和各步 G；旁边显示 G1∪G2 及最终目标。下方一条简短失败分支展示“未通过→不提交”。不要再堆两张生成 H&E 与 R1 重复。

## 精简补实验与医生工作量

这是针对 R2 的最小可解释研究方案，不是经过 power analysis 的临床验证样本量。

1. **机器执行主队列**：74 个开放绑定，每个绑定预选 3 个不同来源 patch，先做一个标准强度，共至多 222 条结构化请求。同一 profile 优先来自不同 WSI/患者。若可用病例不足，报告 shortfall，不补挑到成功为止。前置资格标准冻结，保留候选筛选数与排除原因。
2. **强度边界补充**：优先 24 个 patch（BCSS/GLaS/PANDA 各 8），选具有明确强度定义的操作。每个增加一档更高请求，报告实际可达效果和拒绝情况。R2 只讨论幅度兑现；系统性 3–5 档单调轨迹留在 R4。重复请求可复用，不必另起一套大队列。
3. **有序程序**：上述 12 个程序，尽量复用主队列源图。明确一条两步程序对应一个请求、两个执行步骤，两个分母分别报告。
4. **医生审核**：优先 1 位医生审核 36 个预先抽样结果，每例看 source H&E、source/target tissue/nuclei masks 和指令。按操作层级平衡，并包括未达到请求的例子。问三项：操作含义是否正确、局部改变是否明显不合理、保留对象是否被不恰当地改动；另留“信息不足”。按 2–3 分钟/例约 72–108 分钟，加 20–30 分钟校准。它是专家可接受性抽查，不能报告医生间一致性。
5. **可选第二位医生**：复核其中 12 例，按约 30–45 分钟预算；这样只能报告小样本一致性，不能包装成大型盲评。

**不需要医生重新画整张 mask。** R2 中的标签面积、程序添加事件、保留像素和约束检查都可直接计算。医生新画目标 mask 只有在要评价“与唯一人工目标的像素重合度”时才需要，而反事实目标通常不唯一。既有辅助结构不存在时也不能为省标注而声称已验证该结构保护；选择已有可靠结构证据的子集，或明确该能力未评估。

生成 H&E 的细胞计数、诊断改变及真实感评分属于后面的 Results，避免在 R2 重复消耗医生时间。医生只看 mask 的结论不得外推成生成图像病理可信度。
