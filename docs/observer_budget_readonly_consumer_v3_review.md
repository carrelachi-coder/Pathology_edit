# Adapter v2 捕获的只读验证消费者 v3：审查材料

本分支基于草稿 PR #9 的版本化 Adapter v2 捕获。它新增独立的 30/60 秒 policy、只读验证包装、worker 和进程门禁；旧 policy/gate/worker 与旧捕获组件不变。没有真实 witness、S07、H&E、完成标记发布或患者资格更新。

## 身份与时限

`validation_budget_policy_v3_budget.py` 固定五个生产者组件的 SHA：Codec v2、预算候选、Adapter v2 合同、Adapter v2 和其基础验证器。`capture` 单流预算 30 秒，`compare` 双流预算 60 秒；请求数据不能自行设定时限。消费者身份另含 policy、包装器、gate 和 worker 的文件 SHA。gate 在子进程启动前核对生产者，在返回后复核生产者、消费者、policy、兼容标识与请求哈希。

包装器复用 Adapter v2 基础验证器的 `_prepare`、逐事件 `_checked_events` 和 `_finish`，B/C 每条流只遍历一次；完整 receipt、数组、事件顺序和字段均按原合同严格核验。worker 固定 `publish=False`，gate 不发布接受证明；超时、非零退出、错误绑定或损坏证据均返回 HOLD。

## 当前验证范围

本地指定集合 **146 项通过**，包括 13 项新边界测试以及旧只读预算、Adapter v2 和 Codec 回归。新测试覆盖真实子进程的 30/60 秒传递、旧捕获拒绝、生产者 pin 改动时启动前拒绝、伪造生产者身份、Full Capture 数组损坏和超时回收。AST 对照还确认请求解析、进程传输、单流验证及双流逐事件比较函数与已验收 v2 实现一致。均为小型合成输入；尚未在目标服务器验证 2.1M 事件／683 数组的完整耗时和容量。
