# R3 历史表征结果修正版

本文件中的数值来自完成的患者级重算，可用于 R3 的历史表征分析段落。正式 sham 配对形态结果仍未完成。

## 可用于正文的结果段落

在来自 90 个患者组的 300 个历史配对来源中，两种编辑操作在两个冻结编码器下均表现出群体平均的强度响应。对于 Global 路线，肿瘤增加的患者等权严格顺序率在 UNI-2h 和 CONCH 中分别为 85.7%（95% CI 80.4%–90.5%）和 92.6%（88.2%–96.2%），免疫浸润增加分别为 79.3%（73.7%–84.8%）和 77.8%（71.0%–84.0%）。各操作、路线和编码器组合的平均 Moderate 至 Significant 投影增量均为正，且对应描述性患者 bootstrap 区间均位于零以上。完整估计见下表。

Significant／Moderate 位移范数比的患者均值均大于 1。Global 肿瘤增加的比值在 UNI-2h 和 CONCH 中分别为 1.116 和 1.167，免疫浸润增加分别为 1.066 和 1.117。严格顺序率未达到 100%，表明较强目标并未使所有来源获得相同的表征程度顺序。路线和编码器的点估计差异予以保留，本分析没有据此作路线优越性检验。

在每次交换患者级原始操作标签后重新拟合留出方向的检验中，两个编码器、两档强度和两条路线共八个操作特异性比较的 Monte Carlo p 值均为 1/20,001（约 5.0×10⁻⁵）。这是 20,000 次抽样下、零次空分布统计量达到观测值时的分辨率下限，不能写成 p=0。高重叠子集的八个对应比较也达到该抽样分辨率下限。这些检验作为探索性表征证据报告，不与正式形态终点的预设比较家族混同。

上述结果支持历史生成系列在计算表征中具有群体层面的有序响应及操作方向差异。该历史队列缺少完整匹配的 sham 表征，且存在模型训练患者重叠与谱系未知的限制，不能由此分离有意编辑与重建漂移，也不能将这些比例解释为独立临床验证或实际组织形态的干预成功率。

## 连续剂量相关性的限制

历史 U1 Moderate 的输入 dose 在 300 个来源中完全相同，Significant 有 299 个相同值和 1 个例外来源，该例外来自一位患者。其相关性 bootstrap 仅有 3,117–3,200／5,000 次能够计算系数，其他样本因缺乏充分输入变化而未定义。保留原始计算及有效次数，但不将条件区间作为稳健的连续剂量证据。

历史 U2 两档 dose 的档内范围均小于 0.000008（绝对比例），主要表现为极窄的数值变化。所有剂量相关的绝对 Spearman rho 小于 0.11。该数据适合检验两档系列差异，不能支持连续输入剂量的可靠校准结论。历史 U2 Significant 记录的实际 dose 约为 29.5%，不得改写为当前正式方案的 32% 名义 joint 预算。
