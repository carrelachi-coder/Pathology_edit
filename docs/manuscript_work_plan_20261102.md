## 文章主线与 Results 调整

研究对象是以真实病理视野为起点、在指定形态条件和保留约束下构建的假设状态。当前证据主要支持受控形态干预及其表征响应；诊断价值、真实疾病进展和教学效果需要各自对应的独立验证。

| 新版 Results | 旧 PPT 的处理 | 本节要回答的问题 |
| --- | --- | --- |
| R1 从真实病例构建多个可比较状态 | 保留旧 R1，吸收旧 R2 的简化机制 | 同一来源能产生哪些明确、受约束的形态分支？ |
| R2 指定改变的实现与必要结构的保留 | 以旧 R3 为主体，增加保留结构的定量检查 | H&E 是否实现目标，是否引入额外变化，外观是否可用？ |
| R3 同一形态特征的有序变化系列 | 将旧 R4 改为新 R3 | 强度增加是否对应可观察、可测量的有序变化？ |
| R4 盲法阅片与教学应用探索 | 新增应用实验；当前只有方案 | 医生能否识别、比较并解释这些形态变化？ |

Parser、Planner、candidate compiler、executor 和 verification 的详细机制放入 Methods 和补充材料。六数据集 mask 审计保留为系统可执行性的证据，不代替 H&E 实现质量评价。

## 主图调整方案

### Figure 1 从真实病例构建可比较状态

- 将旧图下方“同一来源及多个模拟分支”上移，成为主视觉。
- 每个分支明确展示生成 H&E，目标组织及细胞 mask 作为小幅辅助。
- 中间系统流程压缩为可读的主链；旧 R2 的规划、候选和失败重规划细节移至补充图。
- 临床语境指令解释为指定形态情景，不将生成分支当成对患者真实治疗响应的预测。

### Figure 2 指定改变的实现与必要结构的保留

- A：同源原图、冻结目标、生成 H&E。
- B：生成图实际形态与目标的比较。先提供适用性明确的自动读出，医生独立标注完成后补充核验。
- C：预先指定的保留区域或特征，以及非目标变化的定量检查。全局重建的结构保留与局部合成的像素保持分别解释。
- D：双编码器 KID 等质量证据，医生真实性结果最后加入。
- 原八列多模型、多器官拼图优先移到补充材料。所有虚拟组织一致性与医生评分数值从正式结果图移除；工作稿可保留明确的待完成空框。

### Figure 3 同源强度系列及其响应

- 将“源自真实病例的生成 H&E 程度系列”放在前面：原图、无编辑生成对照、Moderate、Significant；两种操作分别展示，不暗示是真实纵向进展观测。
- 主定量图优先展示实际形态读出、留出 WSI 投影和严格顺序率及区间。
- 编辑方向偏好、跨路线复现和详细敏感性分析可放主图或补充材料，按篇幅安排。
- 三维展示轴或 UMAP 用作可视化，不能替代原始特征空间的留出 WSI 统计。
- 将“排除图像生成、固定模型干扰”改为“两条路线中观察到一致方向成分”。现有跨路线比较缺少无编辑生成对照，不能独自排除共同生成漂移。

### Figure 4 盲法阅片与教学应用探索

围绕肿瘤占比判断、炎症相关形态比较及程度排序组织。先完成任务定义与图框架，数据收集后填写结果。没有教学干预和前后测时，结论限于作为阅片与教学材料的可行性。

- [ ] 冻结 300 来源 / 90 WSI 的来源、操作、强度、路线与生成文件对应关系，保留版本和哈希。
- [ ] 从保存的选择日志恢复：候选总数 → 组织条件合格数 → mask 编辑及剂量差合格数 → 纳入生成数 → 生成完成数 → 有效测量 / 配对数。无法恢复的分母明确标为未知，不把 300 当原始候选总数；未发现按最终 RGB / embedding 筛选的证据，不指控为挑选漂亮结果。

### P2 建立最小完整主队列并补无编辑对照

在 P0-A、P0-B 及所用路线相关 P1 检查通过后，从已有来源中选一个器官、30 个不同 WSI，每个 WSI 一个来源，固定 global reconstruction。队列规模沿用最新 Word 的可行性设计，不视为通用的充分样本量。

每个来源包含六种状态：

1. 原图。
2. 目标不变、完整经过相同生成流程的无编辑对照（sham）。
3. 肿瘤操作 Moderate。
4. 肿瘤操作 Significant。
5. 免疫操作 Moderate。
6. 免疫操作 Significant。

**六状态、180 张方案的前提是每来源的一张 sham 与四种编辑状态都可比。**完整条件和最终阶段匹配时，复用 120 张历史编辑图及 30 张原图，只新增 30 张 sham；否则统一生成 150 张输出，加 30 张原图，得到 180 张主队列。共用 sham 不可比时不能硬凑 180 张：应先修改协议，按操作或 support 增加匹配对照，并重新计算唯一图数和读片工作量。

对于本轮全局主路线，所有生成状态共用源参考、不含编辑指令的来源描述 prompt、生效随机参数、输出阶段及后处理，改变由目标条件表达；以源 tissue/nuclei 作为 sham 的目标，真实调用完整生成器。记录实际 prompt 内容及哈希，不能只记录相同的 prompt 策略；如方法必须使用操作专属 prompt，应另设匹配对照并更新协议。主要终点统一为全视野生成经后处理、尚未源图局部合成的图像；低染色保护等内部后处理照常统一记录，不能把未经保护图与保护后图混用。若所用入口只能返回源图合成结果，须先修复阶段导出，不能用空 support 合成后的原图充当 sham。

如后续独立采用 Local 合成分析，sham 与其编辑比较必须共用预先冻结的可比非空生成 support，保存合成前后图及 support 哈希。共享区域三臂消融实现可作参考，但其代码存在不代表当前六状态队列已完成，也不能直接把它的固定 seed 或路由假定成正式生效配置。

- [ ] 固定 30 个不同 WSI 的清单及选择规则，不看最终评分后换病例。
- [ ] 核对 checkpoint、推理参数、后处理、参考输入和目标构建记录。
- [ ] 每图记录 `endpoint_stage`、support 哈希、实际权重 / 配置指纹、是否源 RGB 合成、合成参数、合成前后图哈希和实际生效 RNG；确认评价读取的是冻结的终点阶段。
- [ ] 执行 sham 并保存真实运行凭据；核查 noop 与空 support 恢复原图路径，记录失败、不静默剔除。不以观察到像素改变作为唯一有效性标准。

交付标准：形成可追溯的配对队列；共享 sham 时为六状态方案，需要额外匹配对照时按修订协议执行。该队列供新 R2、新 R3 及最后的医生研究共同使用。

### P3 按冻结方案测量实际形态与保留结构

- [ ] 执行 P0-B 已固定的终点、分母、ROI、评价器和统计方案。任何变更都记录理由及协议版本；看结果后提出的终点标为探索性。
- [ ] 分别测量 sham 相对原图、编辑图相对 sham 的变化，以及实际形态与目标的差异。
- [ ] 在预先指定的受保护区域或特征中测量非目标变化；不同生成路线采用含义适当的保留指标。
- [ ] 若报告局部合成，区分 support 外程序保证的像素恒等与 support 内模型保留结构的能力；合成后区域外零漂移不能单独作为模型结构控制能力的证据。
- [ ] 说明自动评价器的标签适配、训练重叠及独立性限制；自动读出不等于医生真值。
- [ ] 按来源 / WSI 保留配对与重复评价关系，不将六种状态算作六个独立病例。
- [ ] 核对每图测量终态和完整性，不仅检查进程退出码；按状态报告分母，并提供缺失 / 不确定的敏感性分析。

交付标准：能够将“mask 中计划的变化”与“H&E 中测得的变化”对应起来，并描述无编辑生成漂移和非目标变化。

### P4 完成有真实结果支撑的初稿

- [ ] 完成 R1–R3、Methods、图注、补充结果和局限性。
- [ ] 明确写出当前结果对形态程度梯度的支持程度；不外推真实时间进展或患者级分级。
- [ ] 完成 R4 的任务、盲法、分析与图框架，等待医生数据后补结果。

暂缓新增器官、扩展更多 primitive、增加第三档强度、全面执行五器官 300 条新请求和新诊断 / 分级模型训练。只有发现阻碍核心结论的证据缺口时，再决定是否恢复这些任务。

### P5 医生研究 最后执行

- [ ] 在 P2 冻结的主队列上安排程度排序及聚焦的形态判断；共享 sham 时为 180 张唯一图，增加匹配对照时同步更新图数和读片工作量。
- [ ] 每来源两种操作分别组成原图、匹配 sham、Moderate、Significant 四图排序组；每操作可共用一个 sham 时共 60 组。若强度之间也需不同匹配对照，则预先调整比较组。允许并列、无法区分和无法判断，重复使用的图像不算新增独立病例。
- [ ] 不将 `原图 < sham < Moderate < Significant` 设为正确答案。分别评价 sham / Moderate / Significant 的干预程度顺序，以及原图与 sham 的额外漂移；原图与 sham 接近或并列可以符合预期。预设强度也不是生成 H&E 真实形态的已知标准。
- [ ] 优先完成盲法阅片和排序，再开展会暴露目标或病例细节的精细标注；子集选择规则预先固定。
- [ ] 精细标注覆盖原图、sham、两种操作和强度，检验实际组织及保留结构。
- [ ] 真实性评价沿用已准备的独立 KID 子集；七生成设置各 60 张加真实图 60 张，共 480 张。现有两位医生各 480 次、共 960 次评阅是工作量计划，不是已获得结果。
- [ ] 保留读者差异、患者 / WSI 配对、无法判断及缺失，不向医生提供模型身份或真假比例。
- [ ] 根据实际结果决定 R4 能支持的应用结论。若未执行医生研究，R4 应留在方案或讨论中，不能呈现为已验证的教学结果。
