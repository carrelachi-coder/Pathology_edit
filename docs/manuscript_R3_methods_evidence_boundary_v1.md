# R3 同源强度系列的方法与证据边界

此文件保存可复用的方法文字和结果写作约束。正式 30 位患者队列尚未形成，因此不能作为已完成的 Results。历史统计运行结束后，应根据冻结数值表另写结果段落。

## 历史表征分析的方法文字

为检验同一来源的两档编辑是否形成有序的表征响应，我们对历史配对队列中的 300 个来源进行分析，按 90 个患者组保留配对关系。每个来源包含肿瘤增加与免疫浸润增加两种操作、Moderate 与 Significant 两档目标，以及局部与全局两条生成路线。患者组由保留的 TCGA 身份映射确定，当前 patient／WSI 分组别名不代表已恢复完整切片 barcode。

UNI-2h 与 CONCH 的缓存特征分别具有 1,536 和 512 个维度。分析使用已保存的原始特征，输入核验包括样本顺序、配对来源、维度及有限性。每次留出一个患者组，在其余患者的 Moderate 输出中分别估计局部与全局平均位移方向，将这两个单位方向等权合成后归一化，得到该操作的留出方向。方向拟合中的路线均值沿用历史分析的来源加权方式。留出患者的来源不参与其自身方向拟合。

对每个来源，将原图至 Moderate、原图至 Significant 的表征位移投影到相应留出方向。严格顺序定义为 Moderate 投影大于零，且 Significant 相对 Moderate 的投影增量大于零。同时报告投影增量、位移范数比和方向一致性。每项效应先在患者内平均，再对患者等权汇总，使用 5,000 次患者级 bootstrap 计算百分位 95% 区间。

操作特异性检验在原始配对特征层面交换患者的 U1／U2 标签，同一患者的全部来源、两档强度和两条路线共同交换。每次置换重新拟合全部留出方向，再计算两种操作的自身方向偏好差。使用固定种子的 20,000 次置换，并保留原固定分数符号翻转检验的真实名称，二者分别报告。剂量与表征响应的 Spearman 相关采用患者聚类 bootstrap 区间，不使用普通独立样本 p 值。

新的独立计算实现使用患者内位移向量之和重建每次置换的训练集合总和，并逐患者扣除留出贡献。它保留原拟合的来源权重、归一化、评估子集和标签交换序列。数值接近判定边界时回退至原始算术。该实现的合成枚举和固定输入数值核验记录与分析身份一并保存。

## 历史结果应如何表述

历史结果只能支持生成图在两个冻结编码器下的计算表征响应。尚无与该历史队列完整匹配的 sham 特征，原图至编辑图的变化可能同时包含重建漂移和有意编辑，因此不能将历史严格顺序率称为 sham 控制的真实形态干预成功率。患者留出拟合不消除生成器或评价模型的训练患者重叠。输入缓存的历史身份记录也不能替代对所有生成图内容哈希和最终后处理阶段的完整追溯。

正文应逐项给出局部／全局、两种操作和两个编码器的实际估计及区间。编码器间或路线间不一致应保留。操作特异性置换与剂量相关属于对应的计算证据，不自动证明病理结构准确或临床独立验证。未完成统计前，不填写趋势、显著性或优于另一条路线的结论。

## 正式 R3 形态分析的方法文字

正式队列的目标是 30 位独立患者，每位患者选取一个按冻结规则完整通过四目标编译及独立 mask 审查的来源。两档名义 joint 预算为 19% 和 32%，组织变化硬下限分别为 14% 和 27%。名义预算、实际 joint fraction 和实际 tissue fraction 分别保留，并核查两档实际 joint 的最小差。目标强度不作为生成 H&E 已实现相应形态变化的已知事实。

来源按患者别名去重。已核查的原始 ROI、倍率表和历史 patch 元数据可以追溯患者组及 ROI 坐标，但没有提供完整 TCGA slide barcode；因此当前 `wsi_id` 是保留的患者／WSI 分组别名，不能写成已核实的完整切片身份。现有 84 个必要容量患者组仅是候选范围，不是拓扑或四目标合格人数。S07 诊断患者尚未纳入旧版技术排除表；如果 S07 的过程证据用于开发新规划方法，该患者须从独立方法验收中排除，并在正式选例前版本化核对相关患者排除规则。

主路线为全局重建。每个来源保留原图、真实经过同一生成流程的 sham，以及 U1／U2 各两档编辑图。共享 sham 仅在完整生成条件及后处理可比时成立。主评价图为统一后处理后、源 RGB 局部合成前的全视野输出。原图与 sham 的漂移单独报告。

U1 主终点为冻结源有效组织区域内的预测肿瘤组织比例。U2 主终点为冻结源 Stroma∪Immune 区域内的预测免疫浸润组织比例。所有状态使用相同源 ROI 和分母，CellViT 炎症细胞密度作为次要终点单独报告。有效零检测须有完成凭据，失败、缺失、不确定和不适用分别保留。

源核条件属于历史 CellViT 衍生伪标签。现有 JSON 可以逐像素重建 151 份核 mask，且现存 AMP-001 权重的内容 SHA 与当前冻结评价器一致；这些事实仍不能证明当年生成 JSON 时使用了该权重，也不能将伪标签称为人工验证的真实核标注。原始执行凭据无法恢复时，Methods 与局限性均应明确这一来源限制。

对必要容量通过的 84 个候选患者组，训练清单的患者级引用审计显示：Cross train／val 分别涉及 78／6 组；Segmentator coarse train 与 val 均涉及全部 84 组，不能据此称 coarse 的候选患者验证集在患者级独立。Segmentator fine train／val／test 分别涉及 62／9／13 组，三份清单在该候选集合中的患者引用互不重叠。上述数字描述的是清单引用，不证明最终 checkpoint 一定使用了相应样本；清单未命中也不证明模型未见过同一患者的其他裁块。FLUX、CellViT 的患者级重叠和 Pix2pix 最终权重训练谱系仍未知。正式入选患者应另存逐患者、逐 checkpoint 的审计，自动评价仍定位为计算证据。

对增加型操作，分别计算 Moderate−sham、Significant−sham 及 Significant−Moderate 的连续配对差，并记录 sham／Moderate／Significant 的严格顺序、精确像素计数并列和逆序。统计以患者为独立单位。四个预设操作×强度的编辑减 sham 比较属于同一 Holm 家族，描述性区间和其他探索性比较明确标注。全请求、有效测量和完整配对分母同时报告。

## 当前不能写入 Results 的结论

现有资格记录为 17 位患者源拓扑通过、含 unknown 上限 19 位、完整四目标批准 0 位。工程验收、A 与历史 receipt 相等、部分 guard 块完整和独立预算优化均不改变这些数字。正式 R3 的主形态效应、配对顺序率、sham 漂移及患者级不确定性仍待完整正式数据。

医生研究继续按计划最后开展。医生评分应评价真实生成形态及程度差异，允许并列、无法区分和无法判断。医生结果尚未产生时，R3 末段应结束于实际已有证据及其限制，不能预写医生认可或跨模型优劣结论。
