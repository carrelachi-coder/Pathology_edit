## R3 完成链

1. 在稳定空闲 GPU 上完成一个冻结目标的真实编译试运行并核验身份、终态和审查制品。
2. 对其余冻结目标执行零自动重试的追加式编译；试运行与后续批次通过严格输入哈希和唯一 case index 合并。
3. 为每个 `review_required` 候选生成精确 mask-only 证据，由 Codex 独立检查；每个候选留下明确的批准或拒绝理由。
4. 每位患者仅在 U1／U2 两种操作的 Moderate／Significant 四个目标各有且仅有一个批准候选时进入正式队列。
5. 冻结最终患者、来源、实际 joint fraction、actual tissue fraction、ROI、模型 checkpoint、训练重叠和全部内容哈希。
6. 生成原图对应的真实 sham，以及 U1／U2 两档编辑 H&E；主评价图使用统一后处理后、源 RGB 局部合成前的全视野输出。
7. 使用固定源 ROI 和分母完成 Segmentator 主终点、CellViT 次要终点、有效零／失败状态以及 sham 漂移记录。
8. 以患者为独立单位完成配对差、严格顺序／并列／逆序、Holm 校正和患者级不确定性；保留实际请求数、有效测量数和完整配对数。
9. 将正式数值、图、Methods、Results、图注和局限性写回论文与 PPT。医生结果未产生时不得预写医生认可或跨模型优劣。
10. 最后执行医生研究，并仅按实际获得的评分更新相应结果。
